# H2H3FirstOrder

## Result

`appCc_h2_h3_h2` proves the smooth three-dimensional estimate for a mixed
`H2` coefficient acting on one derivative of an `H3` covariant tensor, with
output in spectral `H2`.

This is the spatial estimate required by the low-regularity first-order
Ricci-DeTurck coefficient.  Time integrability is intentionally not encoded
here.

Focused verification passed.  The explicitly named module refresh also
completed, so downstream focused checks can import this theorem.
